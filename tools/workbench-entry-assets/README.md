# Entrance recognition icons

These grayscale crops contain only game UI symbols: the Paimon HUD icon, the
world backpack icon, the backpack header, the selected artifact tab, and the
close and back buttons. They were cropped from local 1920×1080 game captures.
The source captures, character portraits, inventory details and account ID
are excluded from the bundle.

BetterGI's ReturnMainUiTask and BvStatus were consulted for the navigation
approach. The bundled crops and Rust matcher are maintained in Workbench.
