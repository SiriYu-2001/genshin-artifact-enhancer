# Third-party components

- yas: https://github.com/1803233552/yas, upstream commit 614245fde088667216b80ff2133a7a44ebeb4d1f, originally https://github.com/wormtql/yas. Its scanner/core packages declare GPL-2.0-or-later. Modified files and the exact locked source tree are supplied in the accompanying yas-corresponding-source.zip. Modifications add deterministic read/observe interfaces, inventory coverage/preview metadata and capture resource fixes. Original copyright belongs to the respective upstream authors.
- The yas source archive preserves the upstream OCR model and dictionary files. PaddleOCR-derived model components retain Apache-2.0 terms: https://github.com/PaddlePaddle/PaddleOCR. The application reuses yas inference; it does not introduce a separate OCR service.
- Frostflake: https://github.com/YuehaiTeam/frostflake. The unmodified Windows control executable is bundled in bin/cocogoat-control.exe (1.3.1.0). Upstream project and its dependencies retain their own rights; this project's GPL license does not relicense that executable. Official distribution: https://cocogoat.work/extra/client .
- Python, NumPy, Pillow, OpenCV, requests, ONNX Runtime, urllib3, certifi, charset-normalizer, idna and PyInstaller retain their respective licenses; the Windows package includes license files under third-party/. PyInstaller uses its bootloader distribution exception.
- Rust dependency sources, checksums and their original license files accompany the matching yas source release. Original project license does not replace dependency licenses.
- Game names and data remain the property of their respective owners. No account inventory, game screenshots or user configuration database is included.

- GOODScanner backend: https://github.com/Anyrainel/GOODScanner, v2026.09.30 / bffc4aad040eac0bb5f10c8b0b2ef86121fb29b5. Uses its genshin_scanner and yas_core libraries (GPL-2.0-or-later). The Workbench headless host adds local authorization, cancellation, five-star scan scope, strict matching, inline equipment receipts, ordinary-artifact staged enhancement, material-rarity checks, durable confirmation journals and foreground-loss protection; no network packet-capture feature is built. Matching source and dependencies accompany the Release. Patch entry: tools/patch_goodscanner.py.
