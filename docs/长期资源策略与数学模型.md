# 长期资源策略与数学模型

2026-10-03。建议模块只读取库存并计算，不操作游戏、不消耗霜或尘。原有即时贪心仍是默认；长期预测是可选的有限周期对照。

## 为什么不能只看稀有度

用户提供的 NGA 主楼（作者“亿个客户”，2026-05-21，tid=46822657）分别列出“期望件数”和随机刷取、定向、重塑的“价值提升”。前者近似 1/p，即平均获得多少件才能出现更好的物品。它不是“越稀有就越该重塑”：正文明确举出稀有沙漏已接近底子极限、重塑收益仍低的例子。

作者实际比较的是某个价值函数的期望增量，并非仅按稀有度排序。保存 HTML 中“圣遗物价值的意义”和“为什么建议手动选择目标分数”两段折叠正文为空，不能据此还原其函数，也不能断言该函数等于 1/p 或负对数概率。

本项目继续采用透明的整套分数，或用户明确选用的 U(S)=min(S,T)。一件很难自然替换的物品可能已经接近上限，对它用尘一样没有收益。因此“自然难替代”是辅助解释，不能作为投资的充分条件，更不应简单使用资源收益除以自然提升概率（p趋于0时会失真）。

## 严格定义

令 I 为当前允许使用的完整库存，F(I) 为满足主属性、4+1、暴击计分上限及保留规则的最优整套分数。F会重新选择散件位置，不局限于当前穿戴。

### 1. 即时贪心

对动作 a（一次指定定制，或一件物品选定两条的一次重塑），随机结果为 X。

- 定制后的可选库存：I∪{X}。
- 重塑后的选择：保留 I，或采用 (I\{i})∪{X}。旧版与新版不是两件。

即时收益 Δ₀(a) 为可选方案最优分数减 F(I)，期望收益 G₀(a)=E[Δ₀(a)]。成功概率 P(Δ₀>ε) 和 G₀/c(a) 分别对应更容易提升、每单位材料更划算。

成本 c：霜的花羽沙杯冠=1/1/2/4/3，尘=1/1/2/2/2。霜与尘不假定汇率。单位成本排序只是可解释的启发式，并不等于整数预算下最优组合。

### 2. 自然刷取基线

给定刷取天数 H、每天实际投入该秘境的树脂 r，普通20树脂结算次数 K=⌊Hr/20⌋。默认每次至少1件五星，再以0.065概率额外1件：

    N = K + Binomial(K, 0.065),  E[N] = 1.065 K

产出均值可显式调整，仍解释为“1件保证＋1件额外”，不适用于任意活动机制。未来库存 D_H 为这些掉落的集合。自然提升是 F(I∪D_H)−F(I)，报告均值及超过0的概率。

生成模型包括：目标秘境两套等概率、五部位等概率、各部位主属性真实不同概率、排除主属性后的副属性加权不放回抽取、秘境初始四条0.2、四档等概率、普通四/五次强化。另一套不会丢弃，可作散件；多件未来掉落允许联合组成新配装。

例如攻击杯主属性概率19.25%，某一种元素伤害杯5%，暴伤头10%。不能沿用“特定属性杯最稀缺”的通用口诀代替个人配置。

部位诊断使用 D_{H,s}：只增加未来掉落中该部位的物品，其他部位维持当前库存，再重算完整配装。它回答“只靠这个部位的新掉落，有多少机会改善今天的整套”，不是该部位在未来整套提升中的唯一贡献。五个诊断结果不能相加，也不是五个独立事件。

### 3. 期末资源的额外收益

本版评估固定策略：“先刷H天，再执行一个根据今天库存指定的动作a”。令 J=I∪D_H。

    Δ_H(a) = max(F(J), F(J经过动作a的结果)) − F(J)
    G_H(a) = E_{D_H,X}[Δ_H(a)]

它比较完全相同的未来掉落路径上“使用”和“不使用”资源的差异，重新优化整套。输出期末额外期望分数、额外提升概率、G_H/c。H=0回到即时问题；默认同时展示0、⌊H/2⌋、H三个时点。

重要：G_H不必随H单调下降。未来其他部位的改善可能让某个散件或套内件更有价值。这也是不能把单件“被替换概率”乘到即时收益上、或简单相加五个部位的原因。

尘的保留决策发生在期末，已观察到D_H，所以可以合法比较旧/新结果。本版没有先观察未来，再冒充今天已经正确保留了某个结果。期间不另行用尘，因此期末这次操作的保底由用户填写状态和本次成本确定。它没有替“等待期间先垫几次保底”定价。

若考虑现在使用尘，则需另外指定只依赖当前信息的保留策略 π(I,X)；不能使用 max(F(I∪D), F((I\{i})∪{X}∪D)) 来假装可在未来反悔。若今天制造霜件且一直保留，固定单次动作的期末得分与期末制造同分布，但材料时机、版本额度和提前使用价值仍不同。

### 4. 真正的长期动态最优（建模，尚未实现）

状态 x_t 包含库存、剩余树脂/时间、霜/尘预算、尘进度与阶段、每套定制额度及重置日；动作包含刷取、等待、定制、重塑、观察结果后保留以及普通培养。

    V_t(x) = max_{a∈A(x)} E[r_t(x,a,X) + V_{t+1}(T(x,a,X))]

终端效用可以是 F(I)、min(F(I),T) 或达标指示函数。若也关心等待期间的实际使用价值，需要阶段收益 r_t，而不仅仅最大化期末得分。剩余资源是否有终端价值必须明确定义，不能默认最后一天全部花光总是最优。

霜、尘成本和额度在A(x)里作为约束；尘的保底变化在T里体现。未知底子应作为候选历史集合或显式信念状态，不能随便赋平均初值。未来新刷出的好底子也会改变重塑选择。

该模型说明即时贪心忽略哪些东西，但不意味着需要训练强化学习。可以用显式模型的有限深度树搜索、滚动重规划或仿真评估，优先保障可解释性。

## 当前计算实现与误差

- 本地Python/NumPy固定随机种子，无网络、Agent或游戏输入。
- 128/512/2048条独立未来路径；相同路径用于各动作、三个时点的配对比较。每条路径每个动作独立抽取一个资源结果。
- 每个模拟库存使用浮点Pareto动态规划完整优化4+1；与现有有理数求解器对照验证。没有将杯、沙等各自最高分直接拼接后忽略暴击封顶。
- 先使用即时计算结果，每部位按保守期望、成功率、乐观期望及可用目标指标各取前三的并集，进行长期比较。输出筛选数量，承认可能遗漏长期最优动作，不能称作全部动作最优。
- 当前库存显示取整、尘未知初始值及可能4/5次强化分别保留上下包络。不对未知历史赋主观概率。
- 概率显示Wilson约95%抽样区间，均值显示标准误差的近似95%区间；零收益样本不显示伪精确的均值[0,0]置信区间，而提示尾部未解析。这是单项模拟误差，不包含模型错误、筛选偏差，也不是整张榜单同时置信保证。极小尾概率、区间重叠和零命中不能给出确定优劣；可提高模拟规模或保留即时枚举建议。

## 明确的边界

新掉落按全部充分培养至+20的潜力评估，普通经验和摩拉充足；不模拟5%序贯停手，故自然发展基线不等于实际强化脚本的产出。评估的是这一理想培养模型下的资源边际收益，不应进一步宣称它一定是实际资源收益的上界或下界。

仅预测目标秘境。现有库存以满级物品为起点，已有未满级胚子的潜力未计入自然发展路径。现有其他套装散件保留，但不虚构其他秘境、合成台或活动的新散件。没有程序消耗五星作为素材或合成材料的路径。

高优先级当前预留物品维持预留，不动态模拟其他角色未来的培养、让装和新需求。没有求解未来多次霜尘收入、所有预算、跨版本额度和新底子的联合优化。未来获得的新尘底子需要更新库存后重算。

## 页面用法

在“祝圣之霜”或“启圣之尘”页展开“长期对照”，启用后填写天数、每天投入这个秘境的树脂、模拟规模。两页设置分别保存，便于独立试验；比较霜尘时请填写相同刷取假设。默认90天、180树脂只是示例，不是对用户习惯的推断。

点击原来的计算按钮，原即时建议保留，下面新增自然提升、部位机会和期末单位材料收益表。没有合适动作或预算为0时仍可看自然刷取对照。推荐作为决策解释，优先保留简单、可重复计算的即时贪心主流程。
