# 圣遗物工坊 · Artifact Workbench

本地运行的原神圣遗物配装、序贯强化与稀缺资源建议工具。Windows / 简体中文 / 1920×1080。运行不需要 Agent、LLM API 或 Computer Use。

## 下载与启动

从 [Releases](https://github.com/SiriYu-2001/genshin-artifact-enhancer/releases) 下载 Windows x64 ZIP，完整解压到可写目录，双击 `ArtifactWorkbench.exe`。程序自动打开本地网页；不要单独移动 EXE。

**Windows ZIP 已包含 GOODScanner 后台、强化兼容读取器、霜华和 ONNX Runtime**，无需手动下载安装或启动插件。EXE 已嵌入 requireAdministrator 启动清单，双击即请求管理员授权（已提升权限时不重复提示）。若已有其他霜华／工坊任务在运行，先退出该插件或结束其任务；不要同时启动多个控制器。点击扫描后工坊会自动切换到游戏，避免按 Win 键切回游戏，因为 Win 是中断键。

已有库存时，配装和资源建议不要求游戏运行。Windows EXE 统一在启动时请求管理员授权；扫描使用 GOODScanner 的 OCR；穿戴使用它的装备接口并另做属性与归属复核。逐阶段强化暂时保留兼容读取／霜华执行器。游戏操作前切到背包圣遗物页。首次使用先在“库存导入”导入 GOODScanner／莫娜 JSON，或选择扫描，再到“角色与预设”确认规则。无需通过配置页底部寻找扫描入口。

## 导入优先的使用流程

库存导入 → 角色与预设 → 只计算配装／资源建议 → 按需强化或换装。自定义预设保存在本地 SQLite，同角色同用途保存时更新原记录，可删除。导入无需游戏或 OCR，参数完整的普通胚仍可参与序贯培养。详见 [导入说明](docs/库存导入与角色预设.md)。

## 功能

- 单角色一套、多角色或同角色多套需求；一次扫描共享库存。
- 主属性白名单、平均词条权重、暴击率计分上限、借用装备规则。
- 按需求顺序优先分配，支持同时使用场景；低优先级让装。
- 五星圣遗物序贯培养，使用阶段放入，按真实等级与词条更新决策。
- 保存本地配装、按顺序换装、强化完成后可自动穿戴并核验。
- 祝圣之霜／启圣之尘的即时建议和未来刷取对照；**只提供建议，不自动消耗霜／尘**。
- SQLite 保存表单、草稿和配置；配置回收站、彻底删除、历史压缩、错误截图保留。

**程序永不消耗五星圣遗物作为素材。** 锁定五星可以是强化目标；素材星级不明确则停止。任务运行时按左／右 Win 或页面显示的备用快捷键中断，也可点击“紧急中断”。已提交给游戏的消耗无法撤销。

## 评分与强化策略

副词条分数为“实际数值 ÷ 平均一次词条数值 × 权重”。主属性用于约束；暴击主属性占用总暴击计分上限，超过上限的暴击副词条不再计分。

在套装、主属性、装备归属和优先级约束下，计算当前满级库存最优整套。对候选枚举剩余普通强化的离散结果，计算最终替换后整套改善的概率；默认概率下界至少 5% 才继续，可配置阈值。每个实际词条节点重新判断。材料不足以到达下一个 +4 节点时，按实际进度继续处理。停手的五星保留，不自动解锁或当素材。

当前主要配装模型为 4+1。多需求使用优先级贪心，不声称全队联合全局最优。

## 霜／尘建议的含义

- 单次霜／尘：离散枚举与动态规划计算整套提升概率、期望提升、单位资源收益。
- 霜：按 1/3 初始四词条模型，成本花／羽 1、沙 2、杯 4、冠 3；每套剩余次数需手动填写。
- 尘：按库存物品、初始底子和账号解明进度计算；花／羽 1，其余部位 2。未知初值会给保守区间。
- 两次定制：固定候选短名单的蒙特卡洛比较，不是第二次自适应全局最优。
- 长期：根据未来天数、每日树脂投入，用共同随机样本比较自然刷取与期末资源投入的增量；不是完整多年最优策略。

尘页面的宽区间主要来自无法从满级属性唯一反推初始底子；当前实现还把联合可行初值简化成各词条独立上下界，因此可能进一步放宽。它不是置信区间，不能把中点当作精确概率。机制假设及模型限制见 `data/` 和 [资源指南](docs/资源规划使用指南.md)、[长期模型](docs/长期资源策略与数学模型.md)。

## 数据与更新

数据仅保存在程序旁的 `runtime/`；数据库为 `runtime/ui/workbench.sqlite3`，配装库为 `runtime/loadouts/library.json`。升级前退出程序并备份整个 runtime，再保留或迁移到新目录。不要公开上传自己的 runtime 或使用后的整个安装目录。

示例配置只是演示模板，不含账号库存、UID 或真实任务记录。公开仓库从干净的单次提交开始，不包含开发历史。

## 从源码启动

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe -m enhancer ui
```

计算模块可直接运行。扫描与换装需要包内适配版 GOODScanner；逐阶段强化仍需要适配版 yas、ONNX Runtime 和霜华。详见 [Windows 构建与依赖](docs/Windows便携版.md)。

```powershell
python -m unittest discover -s tests -v
```

首个公开版本为预览版。离线测试和冻结包测试不等于全部游戏页面、分辨率或新版本均已实测。
